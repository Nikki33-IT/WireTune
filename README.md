## 🎯 Kluczowe Możliwości

- 🚀 **Tuning Stosu Sieciowego (TCP/IP)**: Optymalizacja parametrów takich jak TCP NoDelay, nagłówki ACK, algorytm Nagle'a oraz buforowanie pakietów.
- 🎮 **Dedykowane Profile Konfiguracyjne**:
  - **Competitive Gaming**: Minimalizacja input laga i opóźnień sieciowych (jitter/ping spikes).
  - **Streaming & Content**: Zoptymalizowana przepustowość strumieni audio/wideo.
  - **Balanced / Default**: Przywracanie parametrów fabrycznych systemu jednym kliknięciem.
- 📡 **Diagnostyka w Czasie Rzeczywistym**: Monitorowanie DPC latency, stabilności połączenia i utraty pakietów.
- 🔒 **Bezpieczeństwo**: Automatyczne tworzenie migawek rejestru przed wprowadzeniem jakichkolwiek modyfikacji (1-Click Restore).

## 🛠️ Instalacja & Uruchomienie

```bash
# 1. Klonowanie repozytorium
git clone https://github.com/allynIT/WireTune.git
cd WireTune

# 2. Instalacja zależności
npm install

# 3. Uruchomienie z uprawnieniami administratora
npm start
```
